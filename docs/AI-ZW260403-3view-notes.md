# AI-ZW260403 三视图学习记录

基于 `C:\Users\Ey\Desktop\claude\AI-ZW260403` 中的标准样例，对现有图纸做了结构化读取，重点观察基视图、投影视图、剖视图和图纸尺寸之间的关系。

## 样例结论

### 1. `TZ-QT-006779.Z3DRW`

- 图纸: `A4(V)`
- 视图结构: `1 base + 3 project`
- 典型布局:
  - 基视图在左上区域
  - 一个较薄的投影视图直接位于基视图下方
  - 一个主要侧向投影视图位于基视图右侧
  - 还有一个更大的右侧扩展投影视图

结论:
- 小零件可以使用竖版图纸
- 主体三视图不一定严格只保留三个框，必要时会在右侧补充一个更表达特征的投影视图

### 2. `TZ-TP-000633.Z3DRW`

- 图纸: `A3(H)`
- 视图结构: `1 base + 3 project`
- 典型布局:
  - 基视图位于左中区域，尺寸最大
  - 顶/俯向投影视图位于基视图上方，中心 `x` 基本对齐
  - 右视图位于基视图右侧，中心 `y` 大体对齐
  - 最右侧还有一个进一步展开的投影视图

结论:
- 这是最接近“标准三视图骨架”的样例
- 三视图骨架仍然是“主视图 + 上下对齐视图 + 左右对齐视图”
- 当零件右侧特征较多时，会继续向右扩展，而不是把所有信息挤在主视图附近

### 3. `TZ-ZJ-011571.Z3DRW`

- 图纸: `A3(H)`
- 视图结构: `2 base + 3 project`

结论:
- 当单一基视图不足以表达局部结构时，标准样例会新增独立基视图
- 这说明不能强行把所有零件都压成“一个基视图 + 两个投影视图”
- 自动出图逻辑需要支持“主三视图 + 次基视图/局部说明”的扩展策略

### 4. `TZ-GJ-006199-显示器后壳.Z3DRW`

- 图纸: `A1(H)`
- 视图结构: `1 base + 5 project + 4 section + 9 definition`

结论:
- 大型壳体类零件不是简单三视图，而是“主三视图骨架 + 大量剖视/辅助定义视图”
- 基视图仍是全图中心参考
- 剖视图主要用于表达内部壳厚、筋位、台阶和穿孔等三视图不易清楚表达的特征

## 抽出的通用规则

### 1. 先确定一个最能表达轮廓和主要特征的基视图

- 基视图通常是全图面积最大、信息最完整的视图
- 不是机械地固定为 `front`
- 但从样例看，复杂件也不会轻易把最重要视图放到边角位置

### 2. 标准三视图骨架仍然依赖正交对齐

- 上下关系的视图优先与基视图保持 `x` 对齐
- 左右关系的视图优先与基视图保持 `y` 对齐
- 也就是说，三视图的核心不是“固定 front/top/right 名称”，而是“正交投影关系和对齐关系”

### 3. 图纸不是只放三个框，而是先放三视图骨架，再按特征扩展

- 简单件: `1 base + 2~3 project`
- 中等复杂件: 在右侧继续扩投影视图
- 复杂壳体件: 在三视图基础上增加剖视图和定义视图

### 4. 小件和大件的图纸方向不同

- 小件可以使用 `A4(V)`
- 中等件常见 `A3(H)`
- 大壳体类会直接放大到 `A1(H)`

这对自动出图意味着:
- 纸张尺寸不能固定
- 横版/竖版不能固定
- 需要根据零件外形尺寸和扩展视图数量决定

### 5. 复杂件优先加剖视，不要强行靠 PMI 把信息塞满

- 壳体类样例的剖视图很多
- 说明标准做法不是只靠三视图外轮廓加尺寸
- 对内部特征、壁厚、筋位、台阶，剖视才是主表达手段

## 对自动出图逻辑的直接启发

### 当前有效的部分

- 先分析零件包围盒，再选推荐基视图，这个方向是对的
- 主视图与上下/左右视图做对齐布局，这个方向也是对的

### 当前需要继续增强的部分

- 不能只停留在 `front/top/right` 三视图固定组合
- 需要支持“右侧继续扩展投影视图”
- 需要支持“增加独立基视图”
- 对壳体类零件，需要考虑剖视策略，而不是只做 PMI 自动标注

## 目前最适合作为自动出图基准的样例

- 如果要学习标准三视图骨架，优先参考 `TZ-TP-000633.Z3DRW`
- 如果要学习复杂件扩展策略，优先参考 `TZ-GJ-006199-显示器后壳.Z3DRW`
